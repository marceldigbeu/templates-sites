# Composants externes

Aucun code n'a été copié depuis 21st.dev : le code source des composants y est réservé aux comptes.

- `src/components/CutReveal.jsx` : code original, écrit pour Sillage. Inspiré du principe du composant « Vertical Cut Reveal » de Daniel Petho (licence MIT, https://21st.dev/@danielpetho/components/vertical-cut-reveal) : mots insécables dans un masque, départ décalé. Aucune ligne de son code n'a été lue ni reprise.
- `src/components/Cursor.jsx` : code original (curseur contextuel).

Dépendances : `react`, `react-dom`, `motion` (jamais `framer-motion`). Tailwind n'est pas utilisé : le design est dans `src/style.css`, repris de `../2-table`.
